## Featured Projects

### DVLD — Driving & Vehicle License Department

A multi-tier desktop management system built with C# 13, .NET 10, Windows Forms, and Microsoft SQL Server.

The system manages the complete driving license lifecycle, from applicant registration and application processing to sequential examinations and final license issuance.

**Key Highlights:**
- **3-Tier Architecture:** Separation of Presentation, Business Logic, and Data Access layers.
- **Application Management:** Handles license applications, categories, fees, and application lifecycle transitions.
- **Sequential Testing Workflow:** Enforces Vision, Written, and Practical examination prerequisites.
- **Retake Management:** Automatically handles failed examinations, retake applications, and associated fees.
- **Authentication & User Management:** Login, account activation, session management, and Remember Me functionality.
- **Database Security:** Parameterized SQL queries, relational integrity, and null-safe data mapping.
- **Reusable Components:** Custom User Controls, OOP, inheritance, and event-driven communication.
